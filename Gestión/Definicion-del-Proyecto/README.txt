Resumen del alcance
-------------------
PetConnect es una PWA para centralizar salud animal y conectar dueños de mascotas,
centros veterinarios y cuidadores en Chile.

Incluye: registro de dueños y proveedores, ficha médica, mapa y búsqueda de
proveedores, agendamiento de citas, chatbot orientativo, reseñas y panel admin.

Fuera de alcance: app nativa, pasarela de pago, integración con sistemas clínicos
externos, telemedicina estricta.

Metodología e infraestructura
-----------------------------
  Metodología: Scrum (Product Backlog, sprints, revisiones, retrospectivas)
  Equipo: cuatro integrantes — ver Gestión/Lista-de-Integrantes/
  Infraestructura: MongoDB Atlas, frontend Vercel, backend Render, GitHub
